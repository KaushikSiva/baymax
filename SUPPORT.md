# Support

- Use [GitHub Discussions](https://github.com/KaushikSiva/baymax/discussions)
  for setup questions, demos, and design conversations.
- Use [Issues](https://github.com/KaushikSiva/baymax/issues) for reproducible
  bugs and scoped feature proposals.
- Use private vulnerability reporting for security issues.

This is a research prototype maintained on a best-effort basis. It does not
provide medical, clinical, or emergency support.
